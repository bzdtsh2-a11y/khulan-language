# Хулан

Англи, Солонгос хэлний дүрэм, үг цээжлэх, дасгал, шалгалтын PWA апп.

## Шинэ сургалтын орчин

- YouTube видео хичээлийн холбоос хадгалах
- Өөрийн эрхтэй MP3/M4A/OGG файлыг төхөөрөмжид суулган офлайн сонсох
- PDF судалгаа, ном товхимол хадгалж унших
- PDF дээр Apple Pencil, S Pen, tablet pen эсвэл хуруугаар тэмдэглэх
- Сэдэвт бичгийн шалгалтыг шивж эсвэл үзгээр бичиж өгөх
- Дүрэм, үгийн сан, бүтэц, сэдэвт нийцлээр 100 онооны AI үнэлгээ
- Интерфэйсийн үндсэн `Arial Mon` фонт

Бодит AI үнэлгээнд серверийн `OPENAI_API_KEY` орчны хувьсагч шаардлагатай.
Түлхүүр байхгүй үед шивсэн хариултыг локал rubric үнэлгээгээр шалгана.
Гар бичмэлийг зурагнаас уншиж үнэлэхэд AI түлхүүр шаардлагатай.

YouTube-ээс хамгаалалт тойрч аудио татахгүй. Офлайн санд хэрэглэгчийн өөрийн
эсвэл ашиглах зөвшөөрөлтэй аудио файл л орно.

## Локал асаах

`START_KHULAN.cmd` дээр хоёр удаа дарна. Дараа нь `http://127.0.0.1:4330/` нээгдэнэ.

PDF эхүүдийг вебэд нийтлээгүй. Тэдгээрээс боловсруулсан үгийн дата л аппад ашиглагдана.
