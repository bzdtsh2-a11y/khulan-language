11. topik_ch02_mn_web.json

## Онцлог
- Хуудас бүрийн эх зам (`source_image_path`) хадгалсан.
- Хуудас бүрийн OCR түүхий текст хадгалсан.
- Бүтэцчилсэн дасгал, ranking жагсаалт, тайлбарууд оруулсан.
- Юуг ч устгахгүй байх зорилгоор OCR текстийг бүрэн хадгалсан.
